FORME 网站第一次运行（Windows / XAMPP）

1. 安装 XAMPP（PHP 8.2）和 VS Code。
2. 将整个 Fashion 文件夹放入 C:\xampp\htdocs\Fashion。
3. 在 XAMPP Control Panel 启动 Apache 和 MySQL。
4. 在浏览器输入 http://localhost/Fashion/setup.php 。
5. 创建你自己的管理员账户。
6. 打开 http://localhost/Fashion/ ，登录后进入 Account → Manage store。

如果数据库端口或密码不同，先复制 config.example.php 为 config.local.php，修改副本。
不要双击 PHP 文件，也不要用 VS Code Live Server 运行 PHP。

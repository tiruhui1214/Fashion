# 更新 FORME 设计版本：保留现有商品与数据库

最新版本包含海报布局和分类横幅管理。新增横幅设置使用原有 settings 表，**不用重新导入数据库，也不用重跑 setup.php**。首次安装仍按 WINDOWS-SETUP.md 操作。

## 已经在 XAMPP 运行旧版

1. 先备份整个 `C:\xampp\htdocs\Fashion` 文件夹，并从 phpMyAdmin 导出数据库。
2. 从 GitHub 下载最新 ZIP，解压到一个临时文件夹，例如桌面。不要把整个旧项目删除后再解压。
3. 将新版的 **整个 assets 文件夹**复制到原项目覆盖同名文件，确保其中包含 `fonts` 子文件夹和字体文件。
4. 将新版 `index.php`、`setup.php` 复制到原项目，覆盖同名文件。
5. 将新版的 **整个 app 文件夹**复制到原项目，覆盖同名文件，并保留新增加的文件。新版分类横幅功能需要 app/catalog-banners.php 和 app/admin-catalog-banners.php，不能只更新首页文件。
6. 保留原有 `uploads`、`config.local.php`、`.installed` 和数据库。数据库里的商品、用户、订单和海报设置不需要清空。
7. 启动 Apache 与 MySQL，打开原来的网站地址，按 **Ctrl + F5** 刷新。
8. 检查首页、商品、登录、购物车和后台。字体无需联网，但必须完整复制 assets/fonts。

如果你们已经自己修改过这些 PHP/CSS/JS 文件，先比较差异再合并，以保留你们的代码与文案。不要直接覆盖没有备份的组员修改。

## 通过 GitHub Desktop 管理源码

先保存或提交自己的修改，然后 Fetch origin / Pull 最新 main。处理冲突时保留真实的组员修改；不要通过丢弃本地工作来强行更新。上传图片、本地配置、安装锁和数据库不由 Git 自动同步。

## 这次的设计变化

- 瓷白 `#FCFCFA`、冷石灰 `#F0F0ED`、墨黑 `#202325`，少量灰梅色 `#6C5963` 点缀。
- Cormorant Garamond 标题和斜体，Manrope 正文、导航、表单和后台。字体及 OFL 授权随项目附带。
- 正文 16px；商品名称、价格和表单标签放大；后台表格与说明文字更清楚。
- 分类图片融合编号与胶囊入口、宣传海报取代留白品牌文字区、深色大字品牌页脚。
- 墨黑后台侧栏、白色工作区、统一按钮、图片预览与状态提示。
- 手机菜单支持 Escape 关闭；滚动出现动效尊重系统的“减少动态效果”设置。

原有后台上传的图片和文案不会被这些文件替换。示例插画仍是占位素材；从后台上传自己的产品摄影后，网站会呈现更完整的服装品牌视觉。

## 圆角与微动效更新

这次新增：分类卡片 32px 圆角、底部柔和渐变与胶囊入口；商品图片 18–24px 圆角；按钮胶囊形；表单 12px、后台面板 24px 圆角。最新版本中，大幅首页海报恢复直角；分类卡片、商品图、按钮和表单继续保留圆角。上传图片本身不需要预先修圆角。

桌面鼠标悬停会轻微上浮，分类图片有小幅横向漂移，箭头转向；卡片滚动时错落淡入，选色时图片柔和切换，按钮按下有低透明度涟漪。触屏不启用跟随鼠标的效果。系统开启“减少动态效果”时会跳过这些装饰动画，功能仍然正常。

请按本文上方的完整更新步骤同步 app 与 assets 文件夹，再 Ctrl + F5 刷新。数据库和上传图片不需要更改。

## 最新海报调整

- 顶部大海报和首页宣传海报恢复直角；顶部只保留一个购物入口，移除左右箭头和播放按钮。多张海报通过横向滑动／拖动或键盘左右方向键切换，页面不再自动播放。
- “The art of everyday” 纯文字区域已移除；Homepage content 中的 Campaign banners 移到分类卡片之后、新品之前。
- Women、Men、Kids、All products / New In 以及各子分类页面，均有一条不可点击的横向展示海报。
- 后台入口：**Manage store → Category page banners**。选择页面 → Load banner → 编辑文字、文字颜色及电脑／手机图片 → Save category banner。这里没有按钮链接设置。
- 未配置的子分类使用所属部门的图片；保存子分类后可独立设置。Reset to default / department banner 清除当前页面覆盖设置，不会删除图片文件。
- Homepage 的分类卡片图片仍在 Departments & categories 管理，和分类页顶部横幅分开。
